# 開発状況書

## 現在の段階

Marker Scale Guard本体の初期機能はFL Studio上で期待どおり動作することを確認済みです。コードノート強制の修正と、マーカー付加情報の括弧なし形式への変更が完了し、実機での再確認待ちです。

## 実装済み

- 実機確認用スクリプト`Marker Scale Guard - Preflight Check.pyscript`
- 実機確認ガイド`Marker Scale Guard - Preflight Check.md`
- 本体スクリプト`Marker Scale Guard.pyscript`
- 利用ガイド`Marker Scale Guard.md`
- FL Studio APIの代替オブジェクトを使用した自動テスト`tests/test_marker_scale_guard.py`
- 16進数3桁に加え、2進数12桁のスケール情報を解析可能
- `コードノートに強制`チェックボックスと、±6以内のコード構成音への強制移動
- コードノート強制時は、スケール内外を問わず有効区間内の非コード音を処理対象にする
- ミストーンが0件でも非コード音があれば、強制機能を使用できるダイアログを表示する
- マーカーのキー・スケール情報を`Am_C`、`Am_ad5`、`Am_101011010101`の括弧なし形式で解析する
- マーカーやミストーンがなくても処理用ダイアログを表示し、対象・対象外マーカー数と検出結果を表示する
- コード名だけのマーカーを対象外として扱い、対象外マーカー数へ含める
- `_C[G+]`や`_C[C+F+]`形式でメジャースケール構成音を個別に半音移動する簡易表記

## 検証済み

- 公式Piano roll Scripting APIと、使用するAPIの名称・公開仕様を照合済み
- 実機確認用スクリプトのローカルPython構文検証に合格
- `createDialog()`定義前にノートとマーカーを走査可能
- `getNote()`で取得したノートの`number`と`selected`を直接変更可能
- ノート番号`131`をscoreへ追加し、同じ番号で読み戻し可能
- 同一パターンの異なる2チャンネルから、通常マーカーの名前と時刻を同じ順序で取得可能
- ダイアログ操作中の変更プレビューが、右上の閉じるボタンで閉じた後にロールバックされることを確認
- FL Studio `v26.1.3 [build 5570]`、PPQ 96で実機確認を完了
- `markerCount`は走査前にローカル変数へ保存し、走査中は保存した値を使用する方針を確定
- マーカー文法、コード構成音、メジャースケール変換を自動テスト済み
- マーカー区間、同時刻マーカー、開始位置判定、無効マーカー無視を自動テスト済み
- 矛盾警告、ミストーン検出、移動、衝突判定、選択、削除を自動テスト済み
- 2進数表記と16進数表記の同一性、および不正な2進数表記の拒否を自動テスト済み
- コードノート強制時の候補順、衝突回避、高音側優先、削除、ダイアログ連携を自動テスト済み
- `C_C`のD・F・A・Bと、`Am_C`のB・D・F・Gが強制対象になることを自動テスト済み
- 括弧なしのキー、16進数、2進数表記を受理し、旧括弧形式を拒否することを自動テスト済み
- マーカーなし、無効マーカーのみ、ミストーンなしの場合のダイアログ表示を自動テストへ追加
- 自動テスト37件がすべて成功
- 本体、実機確認用スクリプト、テストコードのPython構文検証に合格
